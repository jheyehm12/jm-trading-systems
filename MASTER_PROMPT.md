## Design Guidelines

- **Premium dark theme** as primary brand (light mode supported via theme toggle)
- **Modern SaaS appearance** — clean typography (Space Grotesk + Inter), cyan accent (`#22d3ee` dark / teal in light)
- **Mobile responsive** — flow-based hero, stacked previews, reduced padding on tablet/mobile
- **Trading + AI branding** — chart wedge hero, mockup previews, case-study layout
- **Professional animations** — Framer Motion section reveals, stats count-up, reduced-motion respected
- **No dev toolbar** in local development (`devToolbar.enabled: false`)
- **Semantic theme tokens** — `text-heading`, `border-theme`, `btn-primary`, etc.
- **Brand mark** — “Jimeno Labs” full / “JL” symbol
